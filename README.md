# Gravity-Transition Readiness: live app

The Gravity-Transition Readiness Model running entirely in the browser: <https://vishram0905.github.io/gravity-readiness-app/>

This repository holds the build script for the static, in-browser version of the app. The model, tests and data are
in [gravity-readiness](https://github.com/vishram0905/gravity-readiness), and the documentation is at
<https://vishram0905.github.io/gravity-readiness-docs/>.

```
python3 build.py      # copies the app from ../gravity-readiness into site/
```
